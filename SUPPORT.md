# Support

## I found a bug

Open a [bug report issue](../../issues/new?template=bug_report.yml).

## I have a question, or I'm not sure how to use something

Use [GitHub Discussions](../../discussions) rather than an issue - issues
are for confirmed bugs with a clear, actionable outcome. Discussions are
the right place for "how do I...", "is X supported", or general feedback
that doesn't need to become a tracked task.

## I found a security vulnerability

Do not open a public issue or discussion - see [`SECURITY.md`](SECURITY.md)
for private reporting.

## I have a Code of Conduct concern

See the "Enforcement" section of [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) -
report privately, not as a public issue.
